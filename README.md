# Color Fun Kids

A cheerful starter app for a kids coloring and color-learning experience.

## What is included
- A colorful palette for kids to choose from
- A paint-by-click coloring board
- Reset, eraser, and rainbow burst actions
- A playful, mobile-friendly layout

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build for production

```bash
npm run build
```
